健康生活 APP 修复版

本次修复：
1. Android 原生麦克风+中文语音识别，不再依赖 WebView 的 SpeechRecognition。
2. 交易、衣橱、待办、计划覆盖、护肤产品、补剂等关键数据同时写入 Android SharedPreferences，退出 APP 后继续保留。
3. 抠图改为“边缘连通背景去除”，减少衣物主体内部同色区域被误删的问题；建议先裁剪，让衣物不要贴到图片边缘。
4. 旋转改为 -180° 到 +180°、1°步进的多角度旋转，并提供 ±45°/±90°快捷键。
5. 删除网页自绘的时间/电量/无线状态栏，让手机系统自己显示。
6. 保存衣物后显示“✓ 已保存到衣橱”，并立即清空上一次衣物照片区域。
7. 今日实际安排的晨间、午间、训练、拉伸等项目全部改为可点击完成，完成状态持久化，不再默认红色完成。

构建方式：GitHub Actions + Capacitor 8.5.2 + Node 22 + Java 21。
